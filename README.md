# Lumina Resort & Bookings 🏨✨

A high-end, visually immersive official website and direct online reservation platform for **Lumina Resort**, built with WordPress and Amelia Booking.

---

## 📌 Project Overview
**Lumina Resort & Bookings** is the bespoke digital presence and direct booking platform tailored exclusively for Lumina Resort. It combines stunning visual storytelling with an integrated, friction-free booking engine (`Amelia Booking`), featuring immersive room showcases, full-width hero headers, and a sophisticated luxury design palette (`#C5A059`).

## 🛠️ Tech Stack & Tools
* **CMS:** WordPress (Gutenberg Block Editor)
* **Booking System:** Amelia Booking Plugin (Direct Property Reservations)
* **Design Standards:** Custom CSS, Responsive Layouts, Luxury Color Grading (`#C5A059`)
* **Environment:** Local WordPress Development Environment

---

## 🚀 Key Features
* **Exclusive Resort Website:** Dedicated luxury brand presence highlighting unique resort accommodations.
* **Immersive Visual Hierarchy:** Full-width cover headers and high-contrast imagery optimized for hospitality branding.
* **Streamlined 50/50 Layouts:** Symmetrical grid presentations for room and suite showcases.
* **Instant Direct Bookings:** Fully integrated reservation workflows allowing guests to book their stay at Lumina Resort seamlessly.
